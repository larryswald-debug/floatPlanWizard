# FloatPlanWizard Solo Boating Safety e-book

This directory is the maintainable publishing source for **Solo Boating Safety: A Practical Guide from Kayaks to Cruisers**.

## Source of truth

The canonical book manuscript is:

`manuscript/solo-boating-safety.html`

Edit that semantic HTML file for textual corrections. The generated PDF, EPUB, DOCX, cover exports, and diagram exports are outputs, not editorial sources. Safety claims remain grounded in the production FloatPlanWizard Solo Boating Safety Guide and its seven companion PDFs.

## Architecture

- `manuscript/` - canonical semantic HTML manuscript.
- `assets/cover/` - original cover artwork and editable layout specification.
- `assets/graphics/source/` - reserved for owner-supplied editable SVG masters; no active instructional figure currently has a matching SVG master.
- `assets/graphics/export/` - owner-supplied PNG publication graphics used by the current PDF, EPUB, and DOCX build paths. All 17 are PNG-only; the later replacements are Figures 1-1, 2-1, 2-2, 4-1, 4-2, 5-1, 6-1, 10-1, 11-2, and 14-1 at 1672x941, Figure 8-1 at 1671x941, Figures 3-1, 3-3, and 7-1 at 1448x1086, the caption-cropped Figure 3-2 at 1429x941, and Figures 3-4 and 11-1 at 1536x1024.
- `styles/` - EPUB stylesheet.
- `scripts/` - deterministic builders and validation.
- `metadata/` - owner-review publishing metadata.
- `dist/` - generated publication deliverables.
- `graphics-inventory.md` - ownership, accessibility, and placement record.
- `source-to-book-audit.md` - source completeness mapping.

## Build

The builders use Python, ReportLab, pypdf, python-docx, Pillow, and lxml. The owner-supplied PNG artwork is validated but never redrawn or regenerated by this repository. The current publication builders use the supplied PNG artwork because their PDF, EPUB/Kindle, and DOCX paths already support those files reliably. All 17 figures are explicitly PNG-only because their current replacements were not supplied with matching SVGs. No application runtime dependency is added to FPW.

Using the Codex bundled publishing runtime in this workspace:

```sh
RUNTIME=/Users/lawrencewald/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3
"$RUNTIME" publishing/solo-boating-safety/scripts/build_all.py
```

Using another Python environment:

```sh
python3 -m pip install -r publishing/solo-boating-safety/requirements.txt
python3 publishing/solo-boating-safety/scripts/build_all.py
```

The build writes:

- `dist/floatplanwizard-solo-boating-safety-guide.pdf`
- `dist/solo-boating-safety-a-practical-guide.epub`
- `dist/solo-boating-safety-kindle-source.docx`
- `dist/solo-boating-safety-cover.jpg`

It also copies the web-download PDF and EPUB to `downloads/`.

Chapter 13 is generated as a usable 84-item checklist in every format. The PDF uses named AcroForm checkbox widgets with printable appearances, the DOCX uses Word checkbox content controls with visible unchecked glyphs, and the EPUB uses labeled checkbox controls with a print-specific visual fallback. Checklist field names are stable across formats and begin with `ch13_`.

## Validation

Run the deterministic validation suite:

```sh
"$RUNTIME" publishing/solo-boating-safety/scripts/validate_book.py
```

The validator requires all 84 Chapter 13 controls, unique cross-format field names, initially unchecked states, printable PDF widget flags and appearances, Word checkbox state definitions, EPUB labels, and EPUB print fallbacks.

Render the PDF for visual review:

```sh
mkdir -p publishing/solo-boating-safety/tmp/pdf-render
pdftoppm -png \
  publishing/solo-boating-safety/dist/floatplanwizard-solo-boating-safety-guide.pdf \
  publishing/solo-boating-safety/tmp/pdf-render/page
```

Render the DOCX with the bundled documents verifier:

```sh
env TMPDIR=/private/tmp "$RUNTIME" \
  /Users/lawrencewald/.codex/plugins/cache/openai-primary-runtime/documents/26.812.11052/skills/documents/render_docx.py \
  publishing/solo-boating-safety/dist/solo-boating-safety-kindle-source.docx \
  --output_dir publishing/solo-boating-safety/tmp/docx-render
```

For final Amazon submission, also open the EPUB in Amazon Kindle Previewer. Kindle Previewer is a separate owner-side approval gate; this repository does not generate or claim a KPF.

The validated build used EPUBCheck 5.3.0. EPUBCheck is intentionally not vendored into this application repository; install or run the current official W3C release as an independent publishing QA tool.

## Image requirements

- Keep informative figure captions and alt text synchronized with the manuscript and `graphics-inventory.md`.
- Run `scripts/build_graphics.py` to validate that the authoritative SVG/PNG assets exactly match the owner manifest, including the explicit PNG-only Figure 1-1, Figure 2-1, Figure 2-2, Figure 3-1, Figure 3-2, Figure 3-3, Figure 3-4, Figure 4-1, Figure 4-2, Figure 5-1, Figure 6-1, Figure 7-1, Figure 8-1, Figure 10-1, Figure 11-1, and Figure 11-2 replacements. The script must not redraw or reinterpret the supplied artwork.
- Do not replace original art with web-sourced material unless publication rights are documented.
- Cover copy is applied deterministically over the separate original cover illustration.
